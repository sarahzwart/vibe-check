# Vibe Check
See how much your friends will actually like your Spotify playlist with this website. I promise you that they definitely won't like it as much as you think they will.

## Features
- Login with Spotify OAuth
- Share a link with friends to connect their Spotify
- Get a match score for each friend based on their top tracks
- See your most divisive song and your music soulmate

## Tech Stack
- Next.js + TypeScript
- Tailwind CSS
- PostgreSQL (Supabase)
- Spotify Web API

## Getting Started

1. Clone the repo
2. Create a Spotify app at developer.spotify.com
3. Set up a Supabase project
4. Copy `.env.example` to `.env.local` and fill in your keys
5. Run `npm install` then `npm run dev`
